Frequently Asked Questions

Everything you need to know about deploying an autonomous booking agent in your stack.

How is this different from sending a standard Calendly or Chili Piper link?

▼

Calendly and traditional tools are passive link-sending forms that force prospects out of their context and experience a 52% abandonment rate. The LumiLore Autonomous Booking Agent conducts an active conversational dialogue: it qualifies the prospect's requirements, checks live calendar availability via authenticated APIs, resolves multi-stakeholder conflicts, and schedules directly inside the chat or phone call—drastically increasing your meeting conversion rate.

What prevents double-bookings across multiple team calendars?

▼

Our backend runs an atomic FreeBusy query against the Google Calendar or Microsoft Graph API at the exact millisecond a prospect reviews available times. When a slot is selected, a distributed lock is placed in AWS DynamoDB to prevent concurrent reservations, and an instant calendar event is written before confirmation is returned.

Does the agent work with our existing CRM and field dispatch tools?

▼

Yes. We provide native bi-directional synchronization with enterprise CRMs including HubSpot and Salesforce, as well as specialized trade dispatch software such as ServiceTitan, Jobber, and Housecall Pro. When an appointment is secured, custom field properties, call notes, and deal stages are updated automatically.

How does the agent handle cancellations or rescheduling requests?

▼

Every invite dispatched via Amazon SES contains a signed, secure 1-click reschedule link. When clicked, the agent immediately displays real-time alternate slots. If a cancellation occurs, the previous calendar slot is released instantly, the CRM status updates to 'Cancelled', and an optional follow-up sequence is queued to win back the prospect.

Is our calendar data private and compliant with Canadian data regulations?

▼

Absolutely. All infrastructure is hosted in AWS Canada Central (ca-central-1), fully compliant with PIPEDA and Canadian data sovereignty guidelines. We use OAuth2 scoped tokens with zero perpetual calendar reading rights. Client booking data is strictly confidential and is never used to train public LLM models.
