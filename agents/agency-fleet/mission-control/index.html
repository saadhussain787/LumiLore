🚀 60-Second Quickstart

Welcome to LumiLore Mission Control, the visual cockpit for managing our 19 autonomous agency operatives. You can start Mission Control in three simple steps:

Step 1: Open Terminal & Start Mission Control

Type this command in your project folder and press Enter:

npm run fleet:gui

Step 2: Open Your Web Browser

Open Chrome, Edge, or Safari and navigate to:

http://localhost:3030

Step 3: Run Any Agent with 1 Click

Click on any agent in the Command Deck (or use the directory tab). Enter target parameters and click "🚀 Dispatch Agent". Output delivers directly into the drawer!

📖 The Plain-English Glossary

Everyday definitions for technical terms used throughout Mission Control:

Mission Control
Your agency's visual command dashboard. Instead of running command-line scripts in a terminal, you run operations through a graphical browser interface.
Why it matters: Makes running the fleet instant for founders and non-technical operators.
Operative / Agent
A specialized AI system calibrated to perform one specific job (e.g. audit websites, write proposals, script video ads).
Why it matters: Functions like having 19 dedicated expert employees on call 24/7.
Division
A functional department in the agency: Growth, Sales, Engineering, Security, Vitality, and Client Delivery.
Why it matters: Groups related operatives together for organized client execution.
Dry-Run (Resilience Mock)
Free test mode powered by LumiLore's offline resilience brain. Runs in under 15ms and spends zero AI API tokens.
Why it matters: Allows endless testing, demos, and verification sweeps with zero cost.
Live OmniRoute Gateway
The live multi-LLM connection to AWS Bedrock (Claude 3.5) and Google Gemini (Gemini 2.5/3.8).
Why it matters: Used when producing live creative deliverables for real client accounts.
Circuit Breakers
Automatic safety valves that switch AI providers if one experiences downtime or rate limits.
Why it matters: Guarantees zero downtime even if an upstream AI vendor has an outage.
Activity Log (.jsonl)
A permanent, append-only company ledger recording every task run across GUI, CLI, and inbound webhooks.
Why it matters: Provides a comprehensive audit trail and exportable CSV reports for clients.
TTFB (Time to First Byte)
The number of milliseconds a website takes to begin responding to a visitor's web browser.
Why it matters: Under 150ms is elite; anything over 1,000ms bleeds leads and Google ranking.
Inbound Lead Bridge
Real-time radar connecting website contact forms and telephone hotline calls directly to Mission Control.
Why it matters: Lets you audit a prospect's site with 1 click the moment they call or fill a form.

❓ FAQ & Troubleshooting

Click any question below to expand the answer:

Q1: What happens if port 3030 is already in use by another app? ▼
Mission Control features automatic port discovery. If port 3030 is occupied, it automatically checks 3031, 3032, etc., and binds to the first free port. The active port is always displayed in the header and terminal output.
Q2: How do I export my company activity log to Excel or Google Sheets? ▼
Scroll down to the Persistent Activity Audit Trail section at the bottom of Mission Control and click the "📥 Export CSV" button. A spreadsheet file will instantly download with every execution record.
Q3: How are deliverables kept separate for different clients? ▼
When you select or create a client using the Client Hub selector in the top bar, all deliverables generated by any of the 19 agents are automatically saved into that client's dedicated folder: .ai/memory/clients/{client-slug}/.
Q4: Can I test the entire 19-agent fleet all at once? ▼
Yes! In the top-right header, click "⚡ Full Fleet Sim". Mission Control will sequentially run all 19 operatives, update their status badges in real-time, and log the complete sweep to the audit trail.
Q5: How do I cleanly stop the Mission Control server? ▼
Simply return to your terminal or command prompt window and press Ctrl + C. The server will terminate all active Server-Sent Events (SSE) connections and shut down in under one second.
